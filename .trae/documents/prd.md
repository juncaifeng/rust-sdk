# MCP Gateway Hub 前端 PRD

## 1. 产品概述
**项目名称**: MCP Gateway Web Dashboard
**目标**: 为现有的 `mcp-gateway-hub` 构建一个现代化的前端控制台，让开发者/管理员能够直观地查看和管理连接到网关的各个节点（Daemons）以及这些节点上暴露的可用工具（Tools）。
**受众**: 内部开发者、系统管理员。
**设计风格**: 采用极简的"Cyber/Terminal"美学或极致干净的现代工具类UI（极简黑白灰，配以高对比度的状态强调色）。我们需要给人一种稳定、专业且响应迅速的控制感。

## 2. 核心功能
1. **全局 Dashboard**: 概览当前连接的节点总数、工具总数等统计信息。
2. **节点（Daemons）管理**: 
   - 列表展示所有已连接的 Daemon。
   - 显示节点 ID、连接状态、挂载的工具数量。
3. **工具（Tools）管理**:
   - 列表展示所有的可用工具，并标明它们归属于哪个 Daemon。
   - 显示工具的名称、描述以及 Input Schema。
4. **实时连接**:
   - 定时刷新或提供手动刷新功能，以便获取最新的 `/v1/daemons` 和 `/v1/tools` 数据。

## 3. 非功能性需求
- 响应式设计（PC 端优先）。
- 支持暗色模式（Dark Mode）。
- 与现有的 Axum 接口 (`http://127.0.0.1:8080`) 通信。

## 4. 数据交互
- `GET /v1/daemons`: 获取节点列表。
- `GET /v1/tools`: 获取全局工具列表（包含 `daemon_id`）。
